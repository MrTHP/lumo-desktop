Bonsai Image (local)

local

Model Desk se connecte au backend du Bonsai Image Demo (PrismML). Le serveur garde les poids du modèle en mémoire et expose /generate sur le port 8000.

Adresse du serveur FastAPI lancé par `./scripts/serve.sh` dans Bonsai-Image-Demo. 
cd ~/Bonsai-Image-Demo
./setup.sh
./scripts/serve.sh

Le premier lancement télécharge les poids et prépare les kernels GPU (plusieurs minutes). Garde `serve.sh` ouvert pendant que tu génères des images.

Bonsai Image Demo est un projet PrismML (licence Apache-2.0). Model Desk fournit seulement l'interface et se connecte à ton serveur local.
